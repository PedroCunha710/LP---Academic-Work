void cleanBuffer ( )

Clears the input buffer to remove any leftover characters.

This function is used to flush the input buffer, clearing any extraneous characters or newline characters left behind by previous user inputs. It ensures that the buffer is clean before accepting new input, preventing issues when reading input later.
